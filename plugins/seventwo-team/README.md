# SevenTwo Team
Task-selected specialist teams with economical model routing, independent review and evidence-based delivery. Adapts to each user’s tools, project conventions and saved preferences.

## Skills
- `seventwo-team:seventwo-team`

## Install
Codex:

```bash
codex plugin marketplace add lucasilverentand/skills
codex plugin add seventwo-team@skills-of-luca
```

Claude Code:

```text
/plugin marketplace add lucasilverentand/skills
/plugin install seventwo-team@skills-of-luca
```

Cursor (team marketplace):

1. Dashboard → Settings → Plugins → Import
2. Paste `https://github.com/lucasilverentand/skills`
3. Install `seventwo-team` (Required or Optional)

Cursor (IDE slash commands):

```text
/plugin marketplace add lucasilverentand/skills
/plugin install seventwo-team@skills-of-luca
```

This plugin owns its skill source under `plugins/seventwo-team/skills/`. Edit those files directly, then run `bun run marketplace:write` to refresh generated manifests and marketplaces.
