# Specialist learning and boundaries
Concrete role prompts and task selection live in [agent-selection.md](agent-selection.md). Use that index as the single role catalog; load only the presets needed for the assignment. Model/provider choices stay in [models-and-usage.md](models-and-usage.md).

## Learning across assignments
Role continuity comes from canonical project knowledge, not a permanently running agent or assumed personal memory. Specialists read relevant existing guidance before work and return evidence-backed changes to the lead. The lead integrates and verifies those changes using [knowledge-and-planning.md](knowledge-and-planning.md).

Distinguish observations, accepted decisions, heuristic inferences and untested hypotheses. Preserve source, date, scope, affected audience/version, and limitations such as sample size when known; do not invent missing metadata. One observation is not a universal rule, repeated agent agreement is not evidence, and a user preference is different from a measured outcome.

Reconcile contradictions rather than appending a diary. Update the existing topical UX, design-system, architecture or operating explanation. Preserve useful rationale when superseding guidance. Put remaining implementation or validation work in the configured tracker, if used; do not create one page per agent, per-run reports, or automatic background learning jobs. Revisit guidance when its topic changes, evidence conflicts, or it appears stale.

## Consistent boundaries
The lead owns mediation, integration, user consultation, and external record writes unless a narrow authorized assignment says otherwise. Specialists provide concrete deliverables and honest evidence. They do not acquire product-owner authority, broaden scope, recursively start teams, or gain tools merely by using a preset.

UX protects behavior and task success; UI protects the accepted visual direction and coherent presentation without sacrificing readability, focus or useful density. Combine them on small changes. Security, accessibility and independent review remain distinct when actual risk warrants that scrutiny, rather than because every task needs a full department.
