# Expo
Offline-first adaptive Expo app architecture, durable local writes, explicit synchronization, reusable components, and cross-platform layouts.

## Skills
- `expo:offline-first-adaptive-app`

## Install
Codex:

```bash
codex plugin marketplace add lucasilverentand/skills
```

Claude Code:

```text
/plugin marketplace add lucasilverentand/skills
/plugin install expo@skills-of-luca
```

Cursor (team marketplace):

1. Dashboard → Settings → Plugins → Import
2. Paste `https://github.com/lucasilverentand/skills`
3. Install `expo` (Required or Optional)

Cursor (IDE slash commands):

```text
/plugin marketplace add lucasilverentand/skills
/plugin install expo@skills-of-luca
```

This plugin owns its skill source under `plugins/expo/skills/`. Edit those files directly, then run `bun run marketplace:write` to refresh generated manifests and marketplaces.
