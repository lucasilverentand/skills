## SevenTwo Team default
For product and open-source work, load the installed `seventwo-team` skill before substantive work. Resolve it through the host's skill discovery; do not assume an author-specific absolute path. Respect an explicit opt-out or narrower workflow.

Activate once in the lead thread for the ongoing task. Delegated agents execute only their assigned role and do not recursively activate or spawn a team. Use the current user's approved profile and project conventions; if consequential tools or preferences remain unclear, follow the skill's discovery-first setup guidance. Keep personal profiles outside the shared package.
